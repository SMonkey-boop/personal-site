# 杨声明 · GitHub Pages

极客终端风格个人主页（Vite + React）。

## 本地预览

```bash
npm install
npm run dev
```

## 构建（复制到仓库用）

```bash
npm run build
```

产物在 `dist/`。若本机无法 `git push`，可：

1. 打开仓库 [SMonkey-boop/shengming.github.io](https://github.com/SMonkey-boop/shengming.github.io)
2. 把 `dist/` 里的文件上传到仓库根目录 **或** 推送整个源码仓库并启用 Actions
3. Settings → Pages → Source 选 **GitHub Actions**（推荐，已有 `.github/workflows/deploy.yml`）

线上地址：https://smmonkey-boop.github.io/shengming.github.io/

## 改内容

编辑 `src/data/profile.js` 或同步更新 `杨声明-Android.md`。
